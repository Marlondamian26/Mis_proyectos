# Guía de Despliegue en Render - Django + React

=======================================================================
RESUMEN: ARQUITECTURA DEL PROYECTO
=======================================================================

Tu proyecto:
- Backend: Django (Python) en carpeta /backend
- Frontend: React (Vite) en carpeta /frontend
- Base de datos: SQLite (incluida con Django, migración requerida)

Deploy en Render:
- Backend → Web Service (Python)
- Frontend → Static Site (Node.js para build)

=======================================================================
PASOS PARA DESPLEGAR EL BACKEND
=======================================================================

1. En Render Dashboard: New → Web Service
2. Configurar:
   - Root Directory: backend
   - Environment: Python
   - Build Command: pip install -r requirements.txt && python manage.py migrate
   - Start Command: gunicorn core.wsgi:application
   - Plan: Free
3. Agregar Environment Variables:
   - KEY: SECRET_KEY_BASE | VALUE: (generar con openssl rand -base64 32)
   - KEY: DEBUG | VALUE: False
4. En ALLOWED_HOSTS de settings.py ya está configurado *.onrender.com
5. Deploy: Manual Deploy → Deploy latest commit

URL resultante: https://tu-backend.onrender.com

=======================================================================
PASOS PARA DESPLEGAR EL FRONTEND
=======================================================================

1. En Render Dashboard: New → Static Site
2. Configurar:
   - Root Directory: frontend
   - Build Command: npm install && npm run build
   - Publish directory: dist
   - Plan: Free
3. Agregar Environment Variable:
   - KEY: VITE_API_URL | VALUE: https://tu-backend.onrender.com/api
4. Deploy: Manual Deploy → Deploy latest commit

URL resultante: https://tu-frontend.onrender.com

=======================================================================
NOTA IMPORTANTE: CORS
=======================================================================

En backend/core/settings.py ya está configurado:
CORS_ALLOWED_ORIGINS = ["https://*.onrender.com"]

Si agregas dominio propio, añadirlo a esa lista.

=======================================================================
PROBLEMAS COMUNES
=======================================================================

Error: "Cannot find manage.py"
→ Solución: Cambiar Root Directory de vacío a "backend"

Error: 401 Unauthorized
→ El backend no tiene el token correcto. Verificar login y que el frontend usa VITE_API_URL correcta.

Error: Blank page en frontend
→ Verificar que VITE_API_URL apunta al backend correcto con /api al final.
